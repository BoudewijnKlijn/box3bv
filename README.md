# Box 2 vs Box 3

## Doel

Vergelijken of beleggen via een BV (box 2: vpb + aanmerkelijk-belang bij uitkering) op lange termijn netto meer oplevert dan privé beleggen in box 3 — en wat het verschil is voor de staatsopbrengst.

## Conclusie

Bij de huidige defaults (box 3: 36%, vpb: 19%, box 2: 24,5%) wint de BV-route voor de belegger zodra het rendement substantieel uit koerswinst komt en de horizon lang genoeg is: uitstel van afrekening tot exit weegt zwaarder dan de dubbele heffing. Bij overwegend dividendrendement of korte horizon is box 3 vaak gunstiger. Voor de staat is BV op lange termijn meestal lucratiever dankzij de exit-heffing, ondanks lagere jaarlijkse inkomsten.
